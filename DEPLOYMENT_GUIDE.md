# Laravel Bar Directory - Deployment Guide

## Server Information
- **VPS/Subdomain**: `server.bestsportsbars.net [866632] (Takeoff 4)`
- **Hosting Type**: VPS Hosting
- **Requirements**: PHP 8.2+, MySQL, Composer, Node.js, Git

---

## Step-by-Step Deployment Instructions

### Step 1: Access Your VPS Server

1. From your hosting dashboard, click **"Login"** or **"Manage"** on `server.bestsportsbars.net`
2. Get SSH credentials (usually provided in VPS management panel)
3. Connect via SSH:
   ```bash
   ssh root@server.bestsportsbars.net
   # or
   ssh your_username@server.bestsportsbars.net
   ```

---

### Step 2: Install Required Software (If Not Already Installed)

```bash
# Update system
sudo apt update && sudo apt upgrade -y

# Install PHP 8.2 and extensions
sudo apt install php8.2-fpm php8.2-cli php8.2-common php8.2-mysql php8.2-zip php8.2-gd php8.2-mbstring php8.2-curl php8.2-xml php8.2-bcmath php8.2-intl -y

# Install Composer
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

# Install Node.js and npm
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Install Git (if not installed)
sudo apt install git -y

# Install MySQL (if not installed)
sudo apt install mysql-server -y

# Install Nginx (if not installed)
sudo apt install nginx -y
```

---

### Step 3: Clone Your Git Repository

```bash
# Navigate to web root (adjust path based on your server setup)
cd /var/www

# Clone your repository
git clone https://github.com/yourusername/bar-directory.git
# OR if using SSH:
# git clone git@github.com:yourusername/bar-directory.git

# Navigate to project directory
cd bar-directory

# Check current branch
git branch

# If you need to switch branch (e.g., main, master, demo)

```

---

### Step 4: Install PHP Dependencies

```bash
# Install Composer dependencies
composer install --optimize-autoloader --no-dev

# If composer install fails due to memory, increase PHP memory:
php -d memory_limit=-1 /usr/local/bin/composer install --optimize-autoloader --no-dev
```

### Step 5: Install Node Dependencies and Build Assets

```bash
# Install Node.js dependencies
npm install

# Build production assets
npm run build

# OR if you want to watch for changes during development:
# npm run dev
```

### Step 6: Configure Environment File

```bash
# Copy environment file
cp .env.example .env

# Generate application key
php artisan key:generate

# Edit .env file with your settings
nano .env
```

**Configure these important settings in `.env`:**

```env
APP_NAME="Bar Directory"
APP_ENV=production
APP_KEY=base64:... (generated by artisan key:generate)
APP_DEBUG=false
APP_URL=https://server.bestsportsbars.net
# OR if you're using a domain:
# APP_URL=https://bestsportsbars.net

# Database Configuration
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=your_database_name
DB_USERNAME=your_database_user
DB_PASSWORD=your_database_password

# Mail Configuration (if needed)
MAIL_MAILER=smtp
MAIL_HOST=your_smtp_host
MAIL_PORT=587
MAIL_USERNAME=your_email
MAIL_PASSWORD=your_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=noreply@bestsportsbars.net
MAIL_FROM_NAME="${APP_NAME}"
```

### Step 7: Create Database

```bash
# Log into MySQL
sudo mysql -u root -p

# Create database and user
CREATE DATABASE bar_directory CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'bar_user'@'localhost' IDENTIFIED BY 'strong_password_here';
GRANT ALL PRIVILEGES ON bar_directory.* TO 'bar_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

**Update `.env` with the database credentials you just created.**

---

### Step 8: Run Database Migrations

```bash
# Run migrations
php artisan migrate --force

# (Optional) Seed database with initial data
php artisan db:seed --force
```

---

### Step 9: Set Proper File Permissions

```bash
# Set ownership (adjust username as needed)
sudo chown -R www-data:www-data /var/www/bar-directory

# Set directory permissions
sudo find /var/www/bar-directory -type d -exec chmod 755 {} \;

# Set file permissions
sudo find /var/www/bar-directory -type f -exec chmod 644 {} \;

# Set storage and bootstrap/cache permissions
sudo chmod -R 775 /var/www/bar-directory/storage
sudo chmod -R 775 /var/www/bar-directory/bootstrap/cache
```

---

### Step 10: Configure Nginx Web Server

Create Nginx configuration file:

```bash
sudo nano /etc/nginx/sites-available/bar-directory
```

Add the following configuration:

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name server.bestsportsbars.net bestsportsbars.net www.bestsportsbars.net;
    root /var/www/bar-directory/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php;

    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

Enable the site:

```bash
# Create symbolic link
sudo ln -s /etc/nginx/sites-available/bar-directory /etc/nginx/sites-enabled/

# Test Nginx configuration
sudo nginx -t

# Restart Nginx
sudo systemctl restart nginx
```

### Step 12: Set Up Queue Worker (If Using Queues)

```bash
# Create systemd service for queue worker
sudo nano /etc/systemd/system/bar-directory-queue.service
```

Add:

```ini
[Unit]
Description=Bar Directory Queue Worker
After=network.target

[Service]
User=www-data
Group=www-data
Restart=always
ExecStart=/usr/bin/php /var/www/bar-directory/artisan queue:work --sleep=3 --tries=3

[Install]
WantedBy=multi-user.target
```

Enable and start:

```bash
sudo systemctl enable bar-directory-queue
sudo systemctl start bar-directory-queue
```

## Troubleshooting

### If you get "500 Internal Server Error":
```bash
# Check Laravel logs
tail -f /var/www/bar-directory/storage/logs/laravel.log

# Check Nginx error logs
sudo tail -f /var/log/nginx/error.log

# Verify file permissions
ls -la /var/www/bar-directory/storage
```

### If you get "Permission Denied" errors:
```bash
sudo chown -R www-data:www-data /var/www/bar-directory/storage
sudo chown -R www-data:www-data /var/www/bar-directory/bootstrap/cache
sudo chmod -R 775 /var/www/bar-directory/storage
sudo chmod -R 775 /var/www/bar-directory/bootstrap/cache
```

### Check PHP version:
```bash
php -v
```

### Check if services are running:
```bash
sudo systemctl status nginx
sudo systemctl status php8.2-fpm
sudo systemctl status mysql
```

## Important Security Notes

1. ✅ **Never commit `.env` file to Git** - It's already in `.gitignore`
2. ✅ Set `APP_DEBUG=false` in production
3. ✅ Use strong database passwords
4. ✅ Keep your server and software updated
5. ✅ Regularly backup your database and files
6. ✅ Use HTTPS (SSL certificate)
7. ✅ Configure firewall (UFW) to allow only necessary ports
