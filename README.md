# Bar Directory

A comprehensive bar directory management system built with Laravel 12 and Vue.js.

## Features

- **Admin Panel**: Complete admin interface for managing bars, events, reviews, bookings, and more
- **Frontend API**: RESTful API for mobile/web frontend applications
- **Role-Based Access Control**: Granular permissions system
- **Bar Management**: Create, edit, and manage bar listings with images, menus, and reviews
- **Event Management**: Organize and manage bar events
- **Review System**: User reviews and ratings for bars
- **Booking System**: Manage bar reservations
- **Claim System**: Bar owners can claim their listings
- **Geographic Management**: Countries, States, Cities, and Regions support

## Tech Stack

- **Backend**: Laravel 12, PHP 8.2+
- **Frontend**: Vue.js 3, Vue Router
- **Database**: MySQL
- **Authentication**: Laravel Sanctum
- **Admin Template**: CORK Admin Template

## Requirements

- PHP 8.2 or higher
- Composer
- Node.js 20+ and npm
- MySQL 5.7+ or MariaDB 10.3+
- Web server (Nginx/Apache)
